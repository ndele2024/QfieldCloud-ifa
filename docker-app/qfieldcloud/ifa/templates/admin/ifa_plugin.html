{# Mode d'emploi #}

Procédure

  1. Dans formulaires/plugins/ifa_menu/metadata.txt, augmenter version=.
  2. Construire l'archive : python install.py --zip.
  3. Déposer ici ifa_menu.zip et metadata.txt.
  4. Au prochain démarrage de QField, chaque appareil propose la mise à jour.

Première installation sur un appareil : QField → Réglages → Plugins → installer depuis une URL, avec l'adresse de l'archive ci-dessus, puis activer le plugin.
